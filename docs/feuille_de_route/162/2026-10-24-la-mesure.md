**Ce que la mesure dit.**

- *La garde ne laisse rien passer qui compte.* Aucun commit de session ne
  change le code sans test ni déclaration ; aucune déclaration ne cache un
  changement du modèle, du portage ou du site ; une seule se discute
  (`373b3fe`), et un seul test sans rapport a fait passer un commit
  (`18cd970`), dont le vrai test existait.
- *Elle refuse à tort, peu, et pour une ligne.* Huit commits de code de
  session sur 159 ont dû se déclarer, tous à raison. Un refus à tort de
  `pousser.sh` ne finit que de trois façons : une déclaration (les huit,
  relues), un test factice (aucun trouvé), ou un envoi abandonné, que seules
  les transcriptions montreraient. Le hook, lui, refuse par construction une
  fois la première retouche de ces commits-là.
- *Deux refus à tort attendent leur occasion.* Le bloc `MESURES_BLOCAGES` de
  `pages.js` compte comme du code : une session qui commiterait seuls les
  fichiers que `regenerer.py` refait serait refusée ; cette semaine, seul le
  robot l'a fait. Et une réparation dont le test, rouge sur `main`, est déjà
  là n'a rien à joindre : elle doit se déclarer, quand les consignes et les
  messages des deux gardes ne nomment qu'« un remaniement, un commentaire ».

**Ce que la session propose, sans le faire.** Une garde ne change qu'avec
l'accord du propriétaire, demandé avant (action 163) :

1. garder la garde telle quelle, hook et envoi : elle tient, pour une ligne
   à écrire sur un commit de code sur vingt ;
2. nommer la troisième raison, « une réparation dont le test, rouge sur
   `main`, est déjà là », dans `CLAUDE.md` et dans les messages de `tdd.py`
   et de `pousser.sh`, sous `Garde-modifiée:` ;
3. trancher `373b3fe` : la forme d'un fichier fabriqué est-elle un
   comportement ? Si oui, le paquet demande un test de sa forme ;
4. le relevé complet des refus : plus de mille pages de `list_events`, à
   confier à une session qui ne fasse que cela, ou à laisser.

Le bloc `MESURES_BLOCAGES` attend que son cas se produise.

**Ce qui reste** : la décision du propriétaire, sur la force de la garde et
ces quatre points (feuille de route).
