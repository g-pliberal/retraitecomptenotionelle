# La retenue : enregistrer sans publier

**Le 21 novembre 2026, la demande.** Le hook `Stop` publie sur `main`, à
chaque fin de tour, tout ce qui est commité, sur quelque branche que ce soit :
`pousser.sh` envoie `HEAD`. Un chantier qui attendait son tour (relecture,
fichiers communs tenus par un autre) ne pouvait donc rien commiter : il
gardait son travail non commité, ou le déposait en patch dans les fichiers du
projet, qu'une autre session réappliquait plus tard sur un `main` qui avait
bougé. Une branche par chantier était exclue : le propriétaire veut ne suivre
que `main`, et une session ne peut pas supprimer une branche sur GitHub (403),
ce qui avait laissé dix branches `claude/*` en septembre. Le propriétaire a
choisi la retenue locale, une garde modifiée avec son accord.

**Ce qui change.** `bash scripts/pousser.sh --retenir "<raison>"` écrit la
raison dans `.git/retenue`, que git ne suit ni n'envoie ; tant que le fichier
est là, le script nu, celui du hook, ne fait rien qu'écrire une ligne
(« retenu : <raison> — N commit(s) en attente »). `--lever` publie avec toutes
les vérifications et n'ôte la retenue qu'après l'envoi : refusé, le travail
reste retenu, et le tour suivant ne publie pas en douce. Aucune référence ne
se crée sur GitHub. La retenue loge dans le dossier commun de git : un agent
isolé dans un worktree la voit aussi. La consigne de `CLAUDE.md` dit de
retenir avant de commiter : commiter d'abord laisserait une fin de tour, ou une
erreur d'API (`StopFailure`), publier entre les deux.

**Les tests** (`tests/test_pousser.py`, vus rouges puis verts) : un travail
retenu ne part pas à la fin du tour, ni sur `main` ni sur une autre
référence ; lever publie ; lever refusé garde la retenue ; `--retenir` veut sa
raison, une option inconnue est refusée ; une tête détachée se retient aussi ;
un worktree voit la retenue ; lever sans rien à publier ôte la retenue. La
relecture sous Fable a trouvé le worktree, l'ordre de la consigne et des tests
trop lâches, tous repris.

**Ce qui reste.** Une retenue ne survit pas au conteneur : avant de finir sans
avoir levé, la session dépose aussi son patch dans les fichiers du projet.
Une copie de secours hors des branches (`refs/attente/…`) reste possible si
une perte se produit vraiment ; elle demanderait de vérifier d'abord qu'une
session peut effacer une telle référence. Retenu, le script ne rattrape plus
`main` : une retenue longue de plus de vingt commits buterait, au lever, sur
le refus de la divergence ; mieux vaut lever souvent.
