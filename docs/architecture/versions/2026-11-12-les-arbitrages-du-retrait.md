# Version du 12 novembre 2026 : les arbitrages du retrait du moteur Python

Le propriétaire a tranché les cinq questions qui retenaient la fin de
l'action 161 (note de décision 0007). L'impôt sur le revenu, la
revalorisation servie avec l'indexation, et la garantie de population
s'écrivent en JavaScript seul, le coût les demandant au pont par lot ; un
calcul agrégé ne reste en Python seul que si le site n'affiche que ce que la
fabrique calcule déjà et s'il n'appelle aucune règle du moteur (table « Où
va quoi »). Les tests du moteur Python passent par une façade servie par le
pont, avant d'être portés. Les douze études restent. L'action se clôt par
fonction, non par paire. La relecture d'une paire n'est plus un préalable à
son retrait : elle ne vaut que pour les quatre fichiers du portage que la
concordance exécute peu.
