# Version du 16 novembre 2026 : le droit daté dans les versions de fiche

Le propriétaire a adopté la note de décision 0009. Une règle que plusieurs
textes réécrivent vit dans les versions de sa fiche, une par réforme et par
public, et non dans une table par loi ni dans une table fusionnée. Le contrat
C.2 le dit : une version porte ce que son texte écrit, une table, une valeur,
un renvoi daté à une autre fiche ou à sa propre rédaction antérieure, chaque
partie avec le texte qui la décide ; ses bornes se lisent dans la disposition
d'application de son texte ; elle a deux preuves, ou dit ce qui manque ; le
champ `code` nomme les fonctions qui appliquent la fiche. La table datée
(C.3) garde les valeurs qu'une date choisit et qui se lisent sans le code.
Les fichiers de régime gardent leurs renvois, qui sont leur droit : l'annexe B
et la ligne 6 du chemin demandent qu'ils soient datés au jour de leur texte,
cités et sans valeur de repli. Rien ne change dans le code avec cette
version ; la migration se fait dans l'action 191, dans l'ordre que donne la
note.
