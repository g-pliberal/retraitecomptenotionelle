# Version du 2 novembre 2026 : ce qui reste en Python

Le principe 4 gagne une phrase, sur la décision du propriétaire du
2 novembre 2026 (note de décision 0006, action 161) : le Python ne disparaît
pas ; il garde, du moteur, les chargeurs dont la fabrique bâtit le paquet et
les types que le pont échange, et retirer un jumeau n'en ôte que les règles.
Le § 7.1 le détaille : le retrait coupe le fichier ; les chargeurs passent
sous `donnees/`, sans méthode de règle ; les types restent, un exemplaire par
langage ; une étude demande au pont, par lot, ce qu'elle appelait du moteur,
et écrit en données la variante qui en remplaçait une fonction ;
`moteur/donnees.json` reste identique à l'octet. Il donne aussi le critère
d'un calcul agrégé que le coût fait et que le site refait : le JavaScript
seul si le lecteur peut en changer le résultat, le coût le demandant au pont
par lot ; le Python seul sinon, son résultat figé au paquet. La table « Où va
quoi » le reprend ; la carte du dépôt et les consignes de `src/` et de
`moteur/` suivent.
